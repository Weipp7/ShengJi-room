# 当前机器人埋底策略：20 个完整复核样本

这 20 个样本均由当前代码中的实际埋底算法生成，不是手工挑选埋底牌。每个样本都经过以下一致性检查：

- 手牌、底牌和亮主牌均来自两副完整牌，任何实体牌不会同时属于两名玩家。
- 如果当前亮主者就是埋底者，其亮主牌一定在摸底前的 25 张手牌中，不会从刚摸起的底牌中“临时亮出”。
- 亮主/反主强度沿时间线严格递增。
- 摸底前 25 张加原底牌 8 张，恰好形成算法实际决策时使用的 33 张牌。
- 最终埋底恰好 8 张，并重新用当前算法计算风险档、底牌分、保留主牌数、绝门和结构破坏情况。

阅读约定：

- `×2` 表示两副牌中的两张完全相同的牌。
- 时间线里的 `【首次埋底】` 是分界线；它前面是发牌阶段的亮主/反主，它后面是有人埋底以后发生的反主和重新埋底。
- “前序反主”只统计当前亮主产生以前已经完成的反主；“当前亮主”本身是否为一次反主会另外写明。
- “风险权重”越大，算法越担心之后再次反主导致底牌暴露在另一种主牌结构下。
- “综合代价”是算法内部用于比较候选埋底组合的相对分数，越低越优；它不是牌局中的得分。闲家埋分会得到明显的负向奖励，所以闲家样本可能出现负数。
- “破坏对子/拖拉机”表示最终底牌拆散了多少个原有结构；这里的统计只用于复核算法，不代表牌局判罚。
