# ITER-011 Bot Bury Strategy

## 功能名称

机器人埋牌策略升级

## 优先级

P1

## 当前状态

Backlog

## 背景

当前 bot 埋牌策略需要从“丢掉不想要的牌”升级为真实玩家视角的风险控制：保主、保分、制造短门、避免把关键控制牌埋掉，并在庄家强弱不同时采用不同策略。

## 需要解决的问题

- 庄家埋牌需要考虑主牌长度、断门、分牌、对子和后续甩牌风险。
- 埋底会影响最终抠底倍率，不能盲目埋高分。
- bot 当前缺少对“保底安全”和“进攻牌型”的权衡。
- 新增甩牌后，埋牌会影响甩牌成功概率和跟牌压力。

## 用户可感知收益

- 机器人庄家更稳定，不会频繁做出明显低级埋牌。
- 闲家抠底和庄家保底的结果更符合玩家预期。
- 与高级出牌策略形成闭环，整局质量更高。

## 实现思路

1. 建立埋牌评分器，按分牌风险、主牌控制、断门价值、对子/连对价值扣分或加分。
2. 生成多组候选底牌，选择总风险最低的组合。
3. 对弱庄、强庄、主少、分多、可断门场景写固定测试。
4. 暂不加入复杂长期记牌，只用当前手牌和合约信息。

## 验收标准

- bot 优先保留主牌控制，不轻易埋掉关键大主。
- bot 在可安全断门时倾向制造短门。
- bot 不会在无保护时集中埋高分导致抠底巨大损失。
- 埋牌数量始终等于底牌数量，不能重复或丢失牌。
- 埋牌结果可由测试解释，不依赖随机。

## 测试方式

- `pnpm test packages/bot/test/bot.test.ts`
- 新增固定手牌：主多分少、主少分多、可断门、有关键对子、有高分底牌风险。
- `pnpm test packages/game/test/scoring.test.ts` 验证抠底结算仍正确。

## 风险和回滚方式

- 风险：评分器过复杂，导致调试困难。
- 控制：评分项保持可枚举，测试只断言关键偏好，不锁死完整排序。
- 回滚：回滚 `packages/bot/src/bury.ts` 和 bot 测试。
