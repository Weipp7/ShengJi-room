# 升级（Shengji）在线对战

四人两副牌「升级」（打百分/拖拉机）在线游戏 MVP：房主创建房间生成房间码邀请好友，昵称即玩、可选房间密码，人数不足可用机器人补位。

## 技术栈

- **Monorepo**：pnpm workspace（`apps/web`、`apps/server`、`packages/{shared,game,bot}`）
- **前端**：React 18 + Vite + TypeScript
- **后端**：Node.js + Express + Socket.IO（内存房间状态，无数据库）
- **测试**：vitest

## 本地开发

```bash
pnpm install      # 安装依赖
pnpm dev          # 同时启动 server (:3001) 和 web (:5173)
pnpm test         # 全量单元/集成测试
pnpm typecheck    # 全 workspace 类型检查
pnpm build        # 生产构建（web 静态产物 + server 单文件 bundle）
```

开发时浏览器访问 `http://localhost:5173`，web 通过 `VITE_SERVER_URL`（默认同源，dev 下由 vite 代理外的 socket.ts 显式指向 `:3001`）连接服务端。

## 环境变量（server）

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `3001` | HTTP/WebSocket 监听端口 |
| `CORS_ORIGIN` | `*` | Socket.IO 允许的跨域来源；生产同源部署可收紧 |
| `ROOM_TTL_MINUTES` | `60` | 闲置房间回收时间（分钟） |

web 构建期变量：`VITE_SERVER_URL`（可选，缺省时与页面同源连接，适配单容器部署）。

## Docker 部署

单容器同时提供静态页面与 WebSocket 服务：

```bash
pnpm build                       # 或直接交给 docker 多阶段构建
docker build -t shengji .
docker run --rm -p 3001:3001 shengji
```

浏览器访问 `http://localhost:3001` 即可创建房间开局；健康检查：`curl localhost:3001/healthz` → `{"ok":true}`。

也可不经 Docker 直接运行生产产物：

```bash
pnpm build
NODE_ENV=production node apps/server/dist/index.js
```

## 游戏规则要点

- 4 人固定两队（0/2 对 1/3），两副牌 108 张，每人 25 张、底牌 8 张
- 发牌过程中即可亮主，25 轮发牌约用 9 秒；首局最后一次有效亮主者抢得庄家，后续局亮主不改变结算预定的庄家
- 开叫可用单张或一对同花色级牌，也可用一对小王/大王；单王和三张以上亮牌非法
- 反主只能用对子，固定强度为：大王对 > 小王对 > 黑桃级牌对 > 红桃级牌对 > 草花级牌对 > 方块级牌对
- 发完牌后有 5 秒全员自由亮主/反主窗口，每次合法反主重置为 5 秒；摸底前无需逐家选择“过”
- 炒底由建房时选择，默认关闭且开局后不可修改；不炒底时庄家埋底后立即开打，炒底时才在埋底后逐家询问反主，反主者拿起当前底牌重新埋 8 张
- 首局 5 秒窗口结束仍无人亮主则废局重发；后续局无人亮主直接打无主，庄家埋底后不可再反主
- 机器人埋底会整体评估保主、保对子/拖拉机、断门和未来改主风险；庄家方倾向做干净底，闲家方在保留末墩控制力的同时倾向埋分争取扣底翻倍
- 机器人出牌使用公开牌史做轻量记牌和概率评估：能推断断门、管理副牌 A/对 A/K、判断安全分主毙牌并评估混合甩牌；仅机器人对家之间会通过公开出牌使用第二张 A、回牌和交接出牌权信号
- 出牌支持单张 / 对子 / 拖拉机 / 同一有效花色的混合甩牌；甩牌按最长拖拉机、对子、单张切分，并检查其他三家当前手牌
- 甩牌失败时强制出可被压住且罚分最高的组件，罚分为 `20 × 该组件张数`；甩牌跟牌须先跟足花色并尽量匹配拖拉机、对子、单张结构
- 副牌甩牌只能由全部主牌且完整匹配所有组件结构的一手牌毙掉；多家毙牌时，有拖拉机比最强拖拉机，否则有对子比最大对子，全单张则比最大单张
- 闲家最终分保留真实负数和高分；末墩闲家赢时，普通牌型按整手张数、混合甩牌按其中张数最多的组件计算 `2^张数` 倍扣底
- 闲家分 `≤0` 为大光、庄家方升3级；`1～39` 为小光、庄家方升2级；`40～79` 庄家方升1级；闲家从80分起上台，每增加40分多升1级，200分及以上升3级
- 级牌打过 A 循环回 2；庄家队内轮转

## 第一版限制

- 房间状态保存在内存中，**服务重启后所有房间清空**
- 无账号体系：玩家身份由浏览器 `localStorage` 中的 playerId（随机 UUID，不对其他玩家下发）标识，它同时充当会话凭证——换设备/清缓存视为新玩家，凭证泄露则可被冒用
- 房间密码明文传输与内存存储：公网部署请务必在反向代理层启用 HTTPS/WSS
- 单实例部署（内存状态不支持水平扩展）
