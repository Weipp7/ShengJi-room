# ITER-011 Bot Bury Strategy

## 功能名称

机器人埋牌策略升级

## 优先级

P1

## 当前状态

Done

## 背景

当前 bot 埋牌策略需要从“丢掉不想要的牌”升级为真实玩家视角的风险控制：保主、保分、制造短门、避免把关键控制牌埋掉，并在庄家强弱不同时采用不同策略。

## 需要解决的问题

- 庄家埋牌需要考虑主牌长度、断门、分牌、对子和后续甩牌风险。
- 埋底会影响最终抠底倍率，不能盲目埋高分。
- bot 当前缺少对“保底安全”和“进攻牌型”的权衡。
- 新增甩牌后，埋牌会影响甩牌成功概率和跟牌压力。

## 用户可感知收益

- 机器人庄家更稳定，不会频繁做出明显低级埋牌。
- 闲家抠底和庄家保底的结果更符合玩家预期。
- 与高级出牌策略形成闭环，整局质量更高。

## 实现思路

1. 建立埋牌评分器，按分牌风险、主牌控制、断门价值、对子/连对价值扣分或加分。
2. 生成多组候选底牌，选择总风险最低的组合。
3. 对弱庄、强庄、主少、分多、可断门场景写固定测试。
4. 暂不加入复杂长期记牌，只用当前手牌和合约信息。

## 验收标准

- bot 优先保留主牌控制，不轻易埋掉关键大主。
- bot 在可安全断门时倾向制造短门。
- bot 不会在无保护时集中埋高分导致抠底巨大损失。
- 埋牌数量始终等于底牌数量，不能重复或丢失牌。
- 埋牌结果可由测试解释，不依赖随机。

## 测试方式

- `pnpm test packages/bot/test/bot.test.ts`
- 新增固定手牌：主多分少、主少分多、可断门、有关键对子、有高分底牌风险。
- `pnpm test packages/game/test/scoring.test.ts` 验证抠底结算仍正确。

## 风险和回滚方式

- 风险：评分器过复杂，导致调试困难。
- 控制：评分项保持可枚举，测试只断言关键偏好，不锁死完整排序。
- 回滚：回滚 `packages/bot/src/bury.ts` 和 bot 测试。

## 执行记录

2026-07-22 启动实现。第一版目标限定为：

- 保留大王、小王、主花色级牌、主 A 等关键主控。
- 在可不埋高分、不拆关键对子时，优先埋完整短副门，制造断门。
- 避免无保护地把 10/K/5 等高分集中埋底。
- 保持输出 8 张、无重复、全部来自手牌。

## 实现结果

- `packages/bot/src/bury.ts` 从单卡排序扩展为候选组评分：
  - `cardBuryCost` 继续保护主牌、分牌和对子成员。
  - `safeVoidGroups` 识别无分、非主、无对子、长度不超过 8 的安全副门。
  - `dealerProfile` 通过主牌张数和关键主控估算弱庄、均衡庄、强庄。
  - 弱庄不主动拿断门奖励；均衡庄和强庄只在补足牌也都是低风险单副牌时生成断门候选。
  - 候选包含默认低风险 8 张，以及“完整埋掉一个安全副门 + 低风险补足”的组合。
  - `candidateCost` 只对候选明确目标断门给奖励，避免断门奖励外溢到整组底牌。
  - `explainBury` 返回最终埋牌、庄家强弱估算和候选列表，用于策略审计和测试；玩家 UI 不展示隐藏底牌。
- `packages/bot/src/play.ts` 在上一轮代码评审中已显式支持跟随 `throw-pairs`，本轮埋牌策略保留该结果。

## 多角色评审记录

- 产品/真实玩家视角：bot 庄家现在能在安全时制造断门，减少“明明可以断门却散埋牌”的低级体验。
- 规则专家：断门候选只在无分、非主、无对子副门上生效；补足牌也必须是低风险单副牌，避免牺牲保底安全。
- QA：新增固定手牌测试，断言偏好而不锁死完整 8 张排序；新增弱庄不强断、强庄安全断门两个对比场景；保留 200 随机手牌合法性测试。
- 对抗评审：
  - 发现：第一版断门奖励按整组候选扣分，读起来可能鼓励用分牌或对子补足 8 张。
  - 采纳：候选显式携带目标断门，只有目标断门拿奖励；补足牌必须满足非主、无分、非对子成员。
  - 发现：文档写了庄家强弱策略，但实现没有建模。
  - 采纳：在 `decideBury` 内部基于主牌长度和关键主控估算弱/均衡/强，不改变外部 API。
  - 二次复审发现：弱庄测试没有覆盖均衡/强庄下的补牌门槛。
  - 采纳：新增 `explainBury` 并补候选层测试，断言不安全补牌时不会生成目标断门奖励候选。

## 未处理事项

- 本轮仍不做长期记牌或基于已出牌信息的精确概率推断；当前只用亮主强度作为“底牌可能再次被接走”的风险代理。
- 强庄目前只提高安全断门倾向，不主动埋分做进攻；主动埋少量低分需要结合后续领牌/保底策略再评估。

## 2026-09-09：反主者重埋与分阵营策略

- 每次埋底后有人反主时，反主者立即拿起当前 8 张底牌形成 33 张手牌，并重新埋 8 张；之后才轮到其余三家继续表态。庄家、庄家首出权和级牌不变。
- 埋底决策输入增加埋底者座位、庄家座位、当前亮主和亮主历史，按座位队伍区分庄家方与闲家方。
- 庄家方以降低底分、保主控、保对子/拖拉机和安全断门为主；弱牌不为断门牺牲高张或牌型。
- 闲家方把底牌视为潜在扣底收益，会在保留主控、对子、拖拉机及末墩能力的前提下主动埋 5/10/K；当前亮主越接近最终强度，埋分越积极。
- 当前亮主仍可能被反时，候选同时在所有更强的潜在主花色下复评，综合平均风险和最坏风险，减少改主后牌形崩坏。
- 候选由低损耗、分底、单/双断门和组合搜索共同产生，再做一轮换牌优化；解释结果暴露阵营、强弱档、底分、保留主数、反主暴露度、潜在主花色和牌型破坏数。
