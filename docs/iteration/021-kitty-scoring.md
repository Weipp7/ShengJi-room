# ITER-021 扣底倍数与闲家真实得分

## 最终规则

- 只有闲家方赢得最后一墩才扣底。
- 普通单张、对子、拖拉机按照最后一墩领出牌型的总张数计算 `2^张数` 倍。
- 成功混合甩牌按照切分后张数最多的组件计算倍数，不使用整套甩牌总张数。
- 多条拖拉机并存时选择张数更多的一条；只有对子和单张时选择对子；全单张甩牌按1张、即2倍计算。
- 庄家方领出甩牌而闲家方完整毙牌赢得最后一墩时，仍按该领出甩牌的最大组件计算。
- 甩牌失败会被强制出小并留下其他手牌，因此不会与该次甩牌扣底同时发生。

示例：

- `AAKKQJJ` 切分为4张拖拉机、2张对子、1张单张，扣底倍数为 `2^4 = 16`。
- `AKQJT9877` 切分为若干单张和一对7，扣底倍数为 `2^2 = 4`。
- 全单张甩牌扣底倍数为 `2^1 = 2`。

## 最终得分

`闲家最终分 = 闲家抓分 + 扣底分 + 庄家方甩牌罚分 - 闲家方甩牌罚分`

最终分不设0分下限，也不限制最高显示值：

- `≤0`：大光，庄家方升3级。
- `1～39`：小光，庄家方升2级。
- `40～79`：庄家方升1级。
- `80～119`：闲家上台，不升级。
- `120～159`：闲家上台并升1级。
- `160～199`：闲家上台并升2级。
- `≥200`：闲家升3级。

牌桌信息与结算界面都显示闲家真实分数；只有前两档显示“大光”“小光”名称。
