# ITER-019 炒底房间规则与摸底前限时亮主

## 状态

Done

## 房间配置

- 大厅使用一个统一的 `炒底 ON/OFF` 开关，默认 `OFF`。
- 普通房间与快速机器人局都使用创建时的当前开关值。
- 配置写入房间并在房间创建后保持不变；等待房间、开放房间列表和牌桌状态栏均展示该规则。

## 摸底前亮主/反主

- 发牌过程中，玩家摸到合法亮主牌即可亮主。
- 发完 25 张后开启全员共享的 5 秒亮主/反主窗口，不逐家询问，也不能通过“过”提前结束。
- 任何非当前亮主者都可在窗口内反主；服务端只接受严格强于当前亮主的合法对子。
- 每次合法反主把截止时间重置为完整 5 秒；非法操作不会重置。
- 客户端固定显示四个花色和王的槽位，只有当前手牌与强度规则允许的选项会点亮，其余选项禁用置灰。

## 无人亮主

- 第一局窗口结束仍无人亮主：本次发牌作废，向所有玩家提示后重新发牌；不增加牌局编号，仍按第一局抢庄处理。
- 后续局窗口结束仍无人亮主：按最高强度的最终无主处理，由既定庄家拿底埋底。
- 无人亮主形成的无主不可在埋底后再反，效果等同已到达大王对的最高强度。

## 埋底后的分支

- `炒底 OFF`：庄家完成首次埋底后立即开始出牌，任何玩家都不能再反主。
- `炒底 ON` 且已有亮主：庄家首次埋底后进入逐家询问；当前有资格的玩家可以用更强对子反主，也可以选择过。
- 埋底后反主成功：反主者拿起当前 8 张底牌，重新埋 8 张，再按既有锁定与恢复规则开始下一轮逐家询问。
- 庄家身份与首出权在后续局和埋底后反主过程中均不改变。

## 关键校验

- 共享窗口使用服务端绝对截止时间，迟到请求会被拒绝。
- 当前亮主者必须等另一名玩家成功反主后才能恢复反主资格。
- 机器人遵守同一窗口、强度和房间规则；没有埋底后反主可能时，机器人埋底评估不再计算虚假的未来改主风险。
- 单元和集成测试覆盖默认配置、房间投影、窗口续时、首局重发、后续局无人亮主、不炒底直开、炒底逐家询问和按钮置灰。
